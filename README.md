# 💊 YuMeiPian Visual Odyssey (愈美片迷幻视觉艺术)

基于愈美片素材打造的纯视觉互动艺术网页，参考经典彩虹漂浮与碰撞渲染逻辑，包含 15 种风格，零文字，每次刷新自动轮换风格。

## 特性

- **15 种视觉风格**：涵盖彩虹反弹、万花筒迷幻螺旋、3D 星际虫洞、零重力黑洞、霓虹数码流星雨、混沌吸引子、复古蒸气波地平线、DNA 双螺旋等。
- **高帧率与低占用**：采用初始化色相缓存预渲染机制，完全硬件加速，GPU 占用极低，高帧率丝滑运行。
- **原色与彩虹交织**：保留清晰可辨的高精度原色药盒与铝箔药板，并配合彩虹光晕药盒交错悬浮。
- **设计感右下角切换按钮**：融合拟态磨砂玻璃、流光扫过光效与动态霓虹光晕，每次刷新与切换风格时按钮外观同步蜕变。
- **交互反馈**：支持鼠标轨迹微粒、点击引爆冲击波、空格键 / 方向键即时切换风格。

## 运行方式

双击运行 `start.bat` 即可自动启动本地服务并打开浏览器体验，或使用任意本地静态服务器打开 `index.html`。
